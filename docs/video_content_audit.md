## Section 4: Technical Integration Guide for Next.js / AGS Web Platform

### 1. Privacy-Preserving Lazy-Loaded Embed Component
To ensure adherence to Core Web Vitals, Google PageSpeed, and strict GDPR/privacy guidelines, embeds must use `youtube-nocookie.com` with `loading="lazy"` and an explicit zero-layout-shift container aspect ratio:

```tsx
// src/components/media/VenueVideoEmbed.tsx
import React from "react";

interface VenueVideoEmbedProps {
  embedId: string | null;
  title: string;
  className?: string;
}

export const VenueVideoEmbed: React.FC<VenueVideoEmbedProps> = ({ embedId, title, className = "" }) => {
  // Strict "Use Nothing" policy: Render nothing or fallback to photo gallery if no qualifying video exists
  if (!embedId || embedId === "NONE") {
    return null;
  }

  return (
    <div className={`relative w-full aspect-video rounded-xl overflow-hidden shadow-2xl bg-zinc-950 ${className}`}>
      <iframe
        src={`https://www.youtube-nocookie.com/embed/${embedId}?rel=0&modestbranding=1&playsinline=1`}
        title={title}
        loading="lazy"
        allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share"
        allowFullScreen
        className="absolute inset-0 w-full h-full border-0"
      />
    </div>
  );
};
```
